# 🤖 Бот для оценки состояния улиц (Telegram & VK)

Система для сбора отзывов, оценки состояния городских улиц и анализа полученных данных. Проект поддерживает одновременную работу через **Telegram** и **ВКонтакте**.

## 🛠 Технологический стек
* **Язык**: Python
* **Библиотеки**: Telebot (PyTelegramBotAPI), VK API, Python-dotenv
* **База данных**: SQLite3

## 🚀 Функциональные возможности

### Для пользователей
1. **Выбор роли** при старте работы.
2. **Ввод названия улицы** для проверки или оценки.
3. **Оценка состояния** дорожного покрытия/инфраструктуры.
4. **Добавление текстового комментария** к своей оценке.

### Для волонтёров и администраторов (Закрытая аналитика)
Доступ к расширенной статистике ограничен специальной командой и **паролем**. Модуль выдает:
* Количество активных пользователей (за день / за месяц).
* Среднее количество выставленных оценок за неделю.
* **Динамика изменений**: автоматическое сравнение периодов (если средняя оценка выросла — ситуация улучшилась, если упала — ухудшилась).

## 💻 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone github.com
cd project_tg_bot
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корневой директории проекта и добавьте туда ваши токен-ключи:
```env
TOKEN=ваш_токен_telegram_бота
VK_TOKEN=ваш_токен_сообщества_вконтакте
```

### 3. Запуск ботов

* **Запуск Telegram-бота**:
  ```bash
  python functional/test.py
  ```

* **Запуск VK-бота**:
  ```bash
  python functional/vk_test_bot.py
  ```
